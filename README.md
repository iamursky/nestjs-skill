# NestJS — a Claude skill for the NestJS framework

[![skills.sh](https://skills.sh/b/iamursky/nestjs-skill)](https://skills.sh/iamursky/nestjs-skill)

A Claude skill that teaches Claude to build server-side applications with
**[NestJS](https://nestjs.com)** — the progressive, TypeScript-first Node.js framework. It bundles
a faithful, offline copy of the official NestJS documentation as structured Markdown references,
with a concise, task-oriented guide on top.

## What it does

Ask Claude to build something with NestJS — or anything involving `@nestjs/*` packages, the `nest`
CLI, controllers, providers, modules, guards/interceptors/pipes, GraphQL, microservices, or
Swagger — and the skill activates so Claude answers from the real docs instead of guessing. It
covers:

- **Building blocks** — controllers & routing, providers & **dependency injection**, and modules
  (shared, global, dynamic)
- **The request pipeline** — middleware, guards, interceptors, pipes & validation, exception
  filters, and custom decorators, with the canonical execution order
- **Techniques** — configuration, databases (TypeORM, Sequelize, Mongoose, Prisma, MikroORM),
  caching, queues, scheduling, events, logging, serialization, versioning, file upload, SSE
- **Security** — Passport/JWT authentication, RBAC/CASL authorization, helmet, CORS, CSRF, rate
  limiting
- **GraphQL** (code-first & schema-first, Apollo, federation), **WebSockets** (gateways),
  **microservices** (TCP/Redis/Kafka/NATS/MQTT/RabbitMQ/gRPC), **OpenAPI/Swagger**, **testing**,
  the **CLI**, and **deployment**

## What's inside

```
skills/nestjs/
├── SKILL.md            # the guide Claude loads on trigger (workflow + reference map)
└── references/         # 136 pages of faithful Markdown from the NestJS docs
    ├── CONTENTS.md     # full navigation, in the docs-site sidebar order
    ├── <overview>.md   # first-steps, controllers, components (providers), modules, …
    ├── fundamentals/   # DI, custom providers, scopes, lifecycle, module ref, testing
    ├── techniques/     # config, database, validation, caching, queues, logging, …
    ├── security/       # authentication, authorization, helmet, cors, csrf, throttler
    ├── graphql/  websockets/  microservices/  openapi/  cli/  recipes/  faq/  devtools/
    └── LICENSE         # upstream documentation license (MIT, Kamil Myśliwiec)
```

Every reference page keeps a `> Source:` link to its file on
[github.com/nestjs/docs.nestjs.com](https://github.com/nestjs/docs.nestjs.com). The live docs are
at https://docs.nestjs.com. This bundle targets **NestJS v11**.

## Installation

### Via `npx skills` (recommended)

```bash
npx skills add iamursky/nestjs-skill
```

### Claude Desktop / Web

1. Download [`skills/nestjs/SKILL.md`](skills/nestjs/SKILL.md)
2. Go to **Customize → Skills → + → Upload a skill**
3. Upload `SKILL.md`
4. The skill activates automatically when you ask about NestJS or `@nestjs/*`

### Manual install for Claude Code

```bash
# Personal (available across all projects)
git clone https://github.com/iamursky/nestjs-skill ~/nestjs-skill
ln -s ~/nestjs-skill/skills/nestjs ~/.claude/skills/nestjs

# Per-project (shared with the team via git)
git clone https://github.com/iamursky/nestjs-skill .nestjs-skill
ln -s .nestjs-skill/skills/nestjs .claude/skills/nestjs
```

## How it activates

The skill triggers automatically when you:

- Ask Claude to build, scaffold, or debug a NestJS application
- Mention `@nestjs/*` packages, the `nest` CLI (`nest new`, `nest g`), or NestJS building blocks
  (controllers, providers, modules, guards, interceptors, pipes, filters)
- Ask about NestJS dependency injection, validation, configuration, or databases
- Work with NestJS GraphQL, WebSockets, microservices, Swagger/OpenAPI, or testing
